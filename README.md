## 先学会判断，再谈买哪款

搜这个词的人最怕的事只有一件：付了住宅 IP 的钱，拿到一个数据库里标着 hosting 的机房段。所以先给三个自己能动手验证的维度，任何商家都适用。

**第一看 ASN 归属。** 查 IP 的 ASN 是 Deutsche Telekom、Vodafone、1&1 这类真实运营商，还是 Hetzner、OVH、Contabo 这类 hosting ASN。这一步用 ipinfo 或 bgp.he.net 几秒就能查完，骗不了人。

**第二看数据库标记。** ipinfo 的 type 字段会写 `isp`、`business` 还是 `hosting`；IPQS、Scamalytics 给的是 fraud score。住宅 IP 通常落在 `isp`/`residential` 一栏，fraud score 偏低。多个库交叉看，只看一家容易被单库的误判带偏。

**第三看实际风控反馈。** 打开 ChatGPT 看是否 `Access denied`，登录 Netflix 看是否提示代理，把 IP 绑到 Stripe 或 Adyen 后台看是否被标记可疑。数据库是纸面分数，风控系统才是最终裁判。

LisaHost 德国这条线的情况是：上游走 **GTT** 国际线路，但 IP 属性被多个数据库识别为**双 ISP 住宅属性**，fraud score 偏低。所谓“双 ISP”，指的是 IP 的住宅身份由两个运营商同时背书，比单 ISP 多一层认证，纯净度更高。这也是它和同机房普通 VPS 的核心差异，不是靠换个 IP 段就能复制的东西。

顺带说清楚一件事：GTT 是 Tier 1 骨干网，说明国际出口质量不错，但它和“中国大陆优化”是两码事。这一点后面讲延迟时会反复用到。
